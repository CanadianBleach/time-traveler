# Time Traveler

A Spotify-inspired music analytics experience that uncovers shared songs across playlists and transforms listening history into an interactive journey.

## Overview

Time Traveler was inspired by Spotify Wrapped and explores the relationships between playlists by identifying overlapping tracks, recurring artists, and listening patterns over time.

The project focuses on turning music data into a visually engaging and exploratory experience, allowing users to “travel” through connections between playlists and rediscover shared songs in a unique way.

## Inspiration

Time Traveler was heavily inspired by the presentation style and excitement of Spotify Wrapped, with a focus on playlist relationships instead of yearly summaries.

The goal was to create an experience that feels personal, interactive, and visually memorable while uncovering hidden connections in a user's music library.
